# Pipe Flow Rate Calculator

**Category:** Engineering & Fluid Mechanics Tools

Calculate pipe flow rates using Darcy-Weisbach (iterative Colebrook-White friction factor) or Manning's formula. Inputs include pipe diameter, length, material roughness (8 preset materials), fluid type (8 presets with density/viscosity), and pressure drop. Outputs flow rate (L/s, m³/h), velocity, Reynolds number, head loss, and friction factor. Shows velocity profile (laminar vs turbulent), and pressure drop vs diameter chart.
